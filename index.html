D DERCKSEN BACKTEST

Overview

DERCKSEN Backtest is a platform for configuring, running, and analyzing quantitative portfolio and options strategy backtests against historical returns data. Any combination of strategies ("legs") can be selected together — the Net Portfolio combines them, with borrowing/lending applied automatically whenever total capital allocated moves away from 100%.

Math & Metrics

Formulas and definitions for every metric used throughout the backtest engine.

Return Metrics

Period Return

Rt = ∑i wi · ri,t / ∑i wi

Weighted average of each holding's compounded return over the rebalance period, normalised by total weight actually matched to available data.

Cumulative Return

Cn = ∏t=1n (1 + Rt) − 1

Compounded growth of the portfolio across all periods in the backtest window.

CAGR (Annualised Return)

CAGR = (1 + Cn)ppy / n − 1

Geometric annualised return, where n is the number of periods and ppy is periods-per-year for the chosen rebalance frequency.

Rolling CAGR

RollCAGRi = (∏t=ii+w−1 (1 + Rt))ppy / w − 1

CAGR applied to every overlapping window of w consecutive periods (default w = 3); the report shows the best and worst window.

Risk-Adjusted Ratios

Sharpe Ratio

Sharpe = Rann / σann

Annualised return divided by annualised standard deviation of returns, resampled at the chosen risk frequency.

Sortino Ratio

Sortino = Rann / σdownside,ann

Annualised return divided by annualised downside deviation, using only periods with negative returns.

Calmar Ratio

Calmar = Rann / |MaxDD|

Annualised return divided by the absolute value of maximum drawdown.

Drawdown & Tail Risk

Maximum Drawdown

MaxDD = mint ( Ct / maxτ≤t(Cτ) − 1 )

Largest peak-to-trough decline in the cumulative return series.

Value at Risk (95%)

VaR95 = Percentile5(Rt)

The 5th percentile of the period return distribution.

Hit Rate

HitRate = count(Rt > 0) / n

Proportion of periods with a positive return.

Benchmark-Relative Metrics

Beta

β = Cov(Rp, Rbm) / Var(Rbm)

Sensitivity of portfolio returns to benchmark returns.

Alpha

α = Rp,ann − Rbm,ann

Annualised excess return over the benchmark.

Tracking Error

TE = stdev(Rp − Rbm) · √(ppy)

Annualised standard deviation of the return difference between portfolio and benchmark, period by period.

Information Ratio

IR = α / TE

Alpha earned per unit of tracking error taken versus the benchmark.

Up / Down Capture

UpCapture = CAGRp(bm>0) / CAGRbm(bm>0)  |  DownCapture = CAGRp(bm<0) / CAGRbm(bm<0)

How much of the benchmark's up-periods and down-periods the portfolio captures.

Outperformance Rate

OutperfRate = count(Rp,t > Rbm,t) / n

Fraction of periods where the portfolio beat the benchmark outright.

Capital, Gearing & Financing

Net Gearing

Gearingt = ∑legs capital_weightleg,t

Total fraction of $1 equity consumed across all capital-eligible legs (Long/Short Portfolio, Long Put, Long Call) in a given period. 1.0 = fully invested; above 1.0 means the excess is funded by borrowing; below 1.0 means idle cash is held. Short Call and Short Put are excluded since no margin/collateral is modelled for them.

Financing Return

Financingt = −(Gearingt − 1) · ((1 + RFR)months/12 − 1)

Interest expense (if geared above 100%) or interest income (if holding uninvested cash below 100%), applied at the static risk-free rate.

Options Leg Mechanics

Put Payoff / Call Payoff

Put: max(K − St, 0) · N  |  Call: max(St − K, 0) · N

Intrinsic value at expiry, where K is the strike (relative to spot = 1), St is the benchmark index level at period end, and N is the position's notional.

Long Call Notional (Fixed vs Weight Mode)

Fixed: N = fixed_pct  |  Weight: N = weight_pct / premium_pct

Fixed mode sizes notional as a set fraction of portfolio value each period. Weight mode spends a fixed fraction of portfolio capital entirely on premium, backing out notional from that spend.

Exercise Rate & Net Cost

ExerciseRate = nexercised / n  |  NetCost = ∑Premium − ∑Payoff

Fraction of periods the option finished in-the-money, and the all-in premium-vs-payoff cost (Long Put/Call) or income (Short Call/Put) over the backtest.

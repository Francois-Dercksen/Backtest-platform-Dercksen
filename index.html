D DERCKSEN BACKTEST

Overview

DERCKSEN Backtest is a platform for configuring, running, and analyzing quantitative portfolio and options strategy backtests against historical returns data.

Math & Metrics

Formulas and definitions for the metrics used throughout the backtest engine.

Alpha

α = Rp − [Rf + β(Rm − Rf)]

Excess return of the portfolio relative to the return predicted by the Capital Asset Pricing Model (CAPM), given its beta.

Beta

β = Cov(Rp, Rm) / Var(Rm)

Sensitivity of the portfolio's returns to movements in the benchmark market returns.

Sortino Ratio

Sortino = (Rp − Rf) / σd

Risk-adjusted return using downside deviation (σd) instead of total volatility, penalizing only harmful volatility.

D DERCKSEN BACKTEST

Overview

DERCKSEN Backtest is a platform for configuring, running, and analyzing quantitative portfolio and options strategy backtests against historical returns data.

Math & Metrics

Formulas and definitions for every metric used throughout the backtest engine.

Return Metrics

Period Return

Rt = ∑i wi · ri,t / ∑i wi

Weighted average of each holding's compounded return over the rebalance period, normalised by total weight actually matched to available data.

Cumulative Return

Cn = ∏t=1n (1 + Rt) − 1

Compounded growth of the portfolio across all periods in the backtest window, expressed as total percentage gain from period 1 to period n.

CAGR (Annualised Return)

CAGR = (1 + Cn)ppy / n − 1

Geometric annualised return, where n is the number of periods in the backtest and ppy is periods-per-year for the chosen rebalance frequency (1 for annual, 4 for quarterly, 12 for monthly).

Best / Worst Period & Rolling CAGR

RollCAGRi = (∏t=ii+w−1 (1 + Rt))ppy / w − 1

Best/worst single period return is simply max/min of Rt. Rolling CAGR applies the CAGR formula to every overlapping window of w consecutive periods (default w = 3) and reports the best and worst window.

Risk-Adjusted Ratios

Sharpe Ratio

Sharpe = Rann / σann

Annualised return divided by annualised standard deviation of returns, computed at the chosen risk frequency (default monthly) and scaled by √(periods-per-year).

Sortino Ratio

Sortino = Rann / σdownside,ann

Annualised return divided by annualised downside deviation, where downside deviation only uses periods with negative returns: √(mean(min(r,0)²)) · √(periods-per-year).

Calmar Ratio

Calmar = Rann / |MaxDD|

Annualised return divided by the absolute value of maximum drawdown, measuring return per unit of worst-case peak-to-trough loss.

Drawdown & Tail Risk

Maximum Drawdown

MaxDD = mint ( Ct / maxτ≤t(Cτ) − 1 )

Largest peak-to-trough decline in the cumulative return series, tracking the running maximum of wealth and measuring the deepest subsequent fall.

Value at Risk (95%)

VaR95 = Percentile5(Rt)

The 5th percentile of the period return distribution — the loss level exceeded only 5% of the time historically.

Hit Rate

HitRate = count(Rt > 0) / n

Proportion of periods with a positive return, out of all n periods in the backtest.

Standard Deviation of Period Returns

σperiod = stdev(R1, R2, …, Rn)

Sample standard deviation of the period-level (e.g. annual) returns, unscaled — a simple measure of period-to-period dispersion.

Benchmark-Relative Metrics

Beta

β = Cov(Rp, Rbm) / Var(Rbm)

Sensitivity of the portfolio's period returns to the benchmark's (SPX) period returns, estimated via the covariance matrix over the common aligned sample.

Alpha

α = Rp,ann − Rbm,ann

Annualised portfolio return minus the annualised benchmark return over the common backtest window — the excess return not explained by simply tracking the index.

Long Put Overlay Metrics

Put Notional (Beta-Matched)

N = βmethod · PortfolioValue

Notional value of protection purchased, sized by beta so the hedge offsets the portfolio's actual market sensitivity. Real Beta uses the full-period beta; Dynamic Beta recomputes an expanding-window beta before each period using only prior data; Custom uses a fixed user-supplied value.

Put Payoff

Payofft = max(K − St, 0) · N

Intrinsic value at expiry, where K is the strike (e.g. 90% of spot for 10% OTM) and St is the benchmark index level at the end of the period, both expressed relative to a starting level of 1.

Net Hedge P&L and Hedged Return

NetPnLt = Payofft − Premiumt   |   Rhedged,t = Rp,t + NetPnLt

Net cost or gain from the option position after subtracting the premium paid, added directly to the unhedged portfolio return to produce the hedged return series.

Exercise Rate

ExerciseRate = nexercised / nyears

Fraction of periods in which the put finished in-the-money (benchmark fell below the strike) and was therefore exercised.

Hedge Effectiveness (Correlation)

Corr = Corr(Rp, NetPnL)

Correlation between the unhedged portfolio return and the net hedge P&L. A more negative value means the hedge pays off precisely when the portfolio falls — the ideal insurance behaviour.

Drawdown Reduction

ΔDD = |MaxDDunhedged| − |MaxDDhedged|

How much smaller the worst peak-to-trough decline becomes once the put overlay is applied. A positive value means the hedge reduced maximum drawdown.

Average Annual Premium Drag

Drag = mean(Premiumt)

Average yearly cost of carrying the insurance, expressed as a percentage of the beta-matched notional, whether or not the put was exercised that period.

Net Hedge Cost

NetCost = ∑ Premiumt − ∑ Payofft

Cumulative premiums paid over the full backtest minus cumulative payoffs received, expressed as a percentage of the initial investment — the all-in cost of running the hedge.

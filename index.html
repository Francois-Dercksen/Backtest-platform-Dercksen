D DERCKSEN BACKTEST

Overview

DERCKSEN Backtest is a platform for configuring, running, and analyzing quantitative portfolio and options strategy backtests against historical returns data.

Math & Metrics

Formulas and definitions for the metrics used throughout the backtest engine.

Alpha

α = Rp − Rbm

Annualised portfolio return minus the annualised benchmark (SPX) return over the common backtest window.

Beta

β = Cov(Rp, Rbm) / Var(Rbm)

Sensitivity of the portfolio's period returns to the benchmark's period returns, estimated via the covariance matrix over the aligned sample.

Sortino Ratio

Sortino = Rann / σdownside,ann

Annualised return divided by annualised downside deviation, where downside deviation only uses periods with negative returns.
